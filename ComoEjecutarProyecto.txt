Primero de todo revisar los .env del cliente como del servidor para tener todos los datos correctos

Para levantar el Back:
 
Tener Docker Desktop instalado.
Clonar el repositorio.
Desde la carpeta Desarrollo-TP ejecutar: 
docker compose up -d
npm run dev en server (npm run build sino se buildeo antes)
docker compose down (para finalizar)
 
5. El backend queda disponible en: http://localhost:3001

Para levantar el Front: (se puede levantar con docker si se configura)

abrir una nueva terminal(bash): (en cd REACT-FULLSTACK/client)

npm run dev (sino se hizo, ejecutar antes npm install)

El frontend quedará disponible en: http://localhost:5173


Verificar front corre : se ejecuta pagina
verificar back corre : curl http://localhost:3001/ (rta eserada de que el servidor funciona correctamente)
verificar bdd corre:  docker ps o
mysql -u root -p consultorioBdd
SHOW TABLES; (debe mostrar 14 tablas)
SELECT COUNT(*) FROM usuario; (contar registros)
