# Documentación del Proyecto - Consultorio Odontológico Carestia

Bienvenido al punto de entrada de la documentación técnica y de gestión del proyecto **Consultorio Odontológico Carestia**, desarrollado para la cátedra de **Desarrollo de Software**.

---

## Índice de Contenidos

1. [Propuesta del Proyecto (Proposal)](proposal.md)  
   Descripción del sistema, tecnologías utilizadas, fundamentación, integrantes, alcance funcional mínimo para Regularidad y adicional para Aprobación Directa.

2. [Instrucciones de Instalación y Ejecución](../README.md#instalación-y-ejecución-recomendado)  
   Guía paso a paso para ejecutar el entorno de desarrollo local con un solo comando (`iniciar.bat` / `iniciar.sh`), requerimientos previos, variables de entorno y usuarios de prueba precargados.

3. [Enlaces a Pull Requests / Merge Requests](pull-requests.md)  
   Registro y enlaces de los Pull Requests integrados durante el desarrollo de la aplicación.

4. [Minutas de Reunión y Avance](minutas.md)  
   Registro cronológico de reuniones de diseño, coordinación de tareas, arquitectura y avance de los integrantes del equipo.

5. [Tracking de Features, Bugs e Issues](tracking.md)  
   Estado detallado de implementación de requerimientos funcionales, aspectos de seguridad y resolución de incidencias.
